# Feature matrix

| Requested capability | 0.3 implementation | Release status |
|---|---|---|
| Native Reach/Soulseek | Experimental direct Java protocol engine; slskd full-download mode | Needs network/device interoperability testing |
| Native Deezer | Public catalog metadata and official previews | Implemented within public API boundaries |
| Stem Player | LALAL.AI upload/split/check/download and two-stem mixer | Needs real API-key test |
| Original Y1 themes | Static asset/palette/background translator with report | Best-effort; unknown vendor widgets remain unsupported |
| Rockbox plugins/games | Android-native plugin menu and bundled tools/games | Not every upstream C plugin binary |
| DSP | Equalizer presets, bass, virtualizer applied per playback session | Needs decoder/headset test |
| Recording | AAC/M4A microphone recording | Needs microphone test |
| FM | Vendor package/API probe and launcher | Depends on Y1 kernel/HAL/vendor app |
| Solar OTA/ROM | Manifest checks, SHA-256, APK installer, variant-gated ROM staging | No automatic flashing by design |
| Wi-Fi UI | Scan/connect/forget/disconnect | Needs Y1 privilege test |
| Bluetooth UI | Discover/pair/unpair/A2DP hidden-API attempt | Needs Y1 privilege and headset test |
| Physical validation | On-device test suite and JSON report | Cannot be completed without a physical Y1 |
